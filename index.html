About

A European community around Mostro.

Open source

Mostro

Mostro is an open-source peer-to-peer Bitcoin protocol using Lightning and Nostr. The protocol and its software are developed by the Mostro project.

Community

MostroEuropa

MostroEuropa brings together European users interested in learning about Mostro, sharing experience, helping other users and contributing to the ecosystem.

Independent

Separate from the project

MostroEuropa is an independent community. It is not the Mostro protocol itself and does not represent the official Mostro project.

Get started

Connect to MostroEuropa.

Choose your client, select the MostroEuropa coordinator, and explore its order book.

Important: Mostro clients may display orders from different coordinators. Select MostroEuropa to see orders published through our coordinator. Always verify the coordinator public key.
Recommended starting point · Beta

Mostro Web App

The official web app is currently in testing. Create a dedicated trading identity and securely back up your recovery phrase. You do not need to use your personal Nostr account.

  1. Open the Mostro Web App using the link below.
  2. Create your trading account and safely store your recovery phrase. Never share it.
  3. Open Settings → Mostro Node.
  4. Select MostroEuropa from the coordinator list.
  5. Return to the order book to browse available orders, create an order, or take an existing one.

Mostro Mobile

  1. Open Settings in Mostro Mobile.

  4. Paste the coordinator public key shown below. The name field is optional.
