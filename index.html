MostroEuropa is an independent European community around Mostro, an open-source peer-to-peer Bitcoin protocol built on Lightning and Nostr.

This website is the public home of the MostroEuropa community. For information about the Mostro protocol, its software and documentation, visit the official Mostro project.

About

A European community around Mostro.

Open source

Mostro

Mostro is an open-source peer-to-peer Bitcoin protocol using Lightning and Nostr. The protocol and its software are developed by the Mostro project.

Community

MostroEuropa

MostroEuropa brings together European users interested in learning about Mostro, sharing experience, helping other users and contributing to the ecosystem.

Independent

Separate from the project

MostroEuropa is an independent community. It is not the Mostro protocol itself and does not represent the official Mostro project.

Community

Talk with the community.

The Telegram community is the main place for discussion, user-to-user help, project news and information about using Mostro. New contributors and people curious about the protocol are welcome.
